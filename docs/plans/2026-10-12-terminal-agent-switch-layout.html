What stays the same in every option

  • Running agent's model: you were right. AO cannot change it in a terminal; the agent's own /model does. So that tab offers no model choice.
  • When the switch happens: a terminal has no "next message" for AO to wait on, so the box carries a Switch button. It is disabled while the agent is working.
  • What the chip shows: the agent always; the model only when AO knows it. A model changed with /model in the terminal is not reflected.
  • Chat: no change to the chat box; only the ⋮ menu goes.
